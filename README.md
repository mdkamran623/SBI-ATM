## 📌 Overview

The **SBI ATM Simulator** replicates the complete user journey of a real ATM kiosk. Designed with enterprise-grade logic, it offers a seamless, responsive experience for testing banking workflows, demonstrating full-stack Python development, or simply exploring a functional ATM interface.

> **Key Differentiator**: Unlike basic simulators, this project implements dynamic denomination dispensing (₹500, ₹200, ₹100), session-based state management, and real-time transaction logging — mirroring core banking standards.

---

## ✨ Architectural Highlights

| Module | Implementation |
|--------|----------------|
| **Session Management** | Token-based state preservation across API calls |
| **PIN Security** | 4-digit validation with attempt throttling |
| **Cash Logic** | Greedy algorithm for optimal denomination breakdown |
| **Transaction History** | In-memory ledger for mini-statement generation |
| **UI/UX** | Fully responsive, mobile-first kiosk interface |
